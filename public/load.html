Load Data — Help

Load experiment data into the CFPS Dashboard

Loading Options

  • Upload CSV — Drag-and-drop or click to browse for a processed results CSV file. The file is cached in your browser so you can navigate between dashboard tabs without re-uploading.
  • Load from Database — Pull data directly from the P902_Results table in cfps.db. No file upload needed — the database is built automatically from CSVs in the repository.
  • Load Cached — If you previously loaded data, it's cached in your browser's IndexedDB. Click "Load Cached" to resume where you left off.
  • Rebuild Database — One-click rebuild of the P902_Results table from all CSVs in data/P902_Results/. The button reads data_manifest.json to discover files, fetches each CSV, and rebuilds the table in your browser using sql.js. Other tables (lots, SO results) are preserved. After adding new CSVs from the AbsQuant analyzer, run python scripts/gen_manifest.py to update the manifest, then click Rebuild.

After Loading

You'll be redirected to the Overview Dashboard automatically. From there, use the navigation tabs to access Curves & Lots, Experiment deep dive, Raw Data, and Reproducibility views.

Clear Cache

Click "Clear" next to the cached data info to remove it from your browser and start fresh.
