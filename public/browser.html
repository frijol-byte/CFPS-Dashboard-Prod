Data Browser — Help

Query the experiment database with SQL

How It Works

The database (cfps.db) is loaded into your browser using sql.js (SQLite compiled to WebAssembly). You can run any SQL query — no backend server is involved.

Writing Queries

Type SQL in the editor and press Run (or Ctrl+Enter). Examples:

  • SELECT * FROM P902_Results LIMIT 100
  • SELECT EXP_ID, AVG(FINAL_CONCENTRATION_WITH_DILUTION) as avg_conc FROM P902_Results GROUP BY EXP_ID
  • PRAGMA table_info('P902_Results') — show column names and types

Table Features

  • Right-click header — Pin/unpin a column so it stays visible while scrolling horizontally
  • Drag header edge — Resize any column by dragging the right edge of its header
  • Horizontal scroll — Tables with many columns scroll horizontally; only ~6 columns are visible at once

Available Tables

P902_Results — experiment data; P902_SO_Results — salt optimization data; layouts — plate layouts; lot_fermentation, lot_lysate, lot_mastermix, lot_std_curves, lot_controls, lot_cf_product, lot_plasmid, lot_premix, lot_pre_so_mm, lot_solubility_enhancer, lot_delivered_material.
