Raw Data Explorer — Help

Browse and export the full dataset

Features

  • Sortable Columns — Click any column header to sort ascending/descending.
  • Column Selection — Toggle which columns are visible in the table.
  • Pagination — Navigate through large datasets using the ← → page buttons.
  • CSV Export — Click ⬇ Export to download the currently filtered and displayed data as a CSV file.

Filters

The global filter panel at the top applies here too — only filtered rows are shown in the table and included in exports.
