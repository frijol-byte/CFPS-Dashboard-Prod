AbsQuant Data Processing — Help

Process raw plate reader output into quantified concentrations

Getting Started

Upload two files to begin analysis:

  • Results file — Your plate reader Excel (.xlsx) or CSV file containing raw fluorescence measurements.
  • Plate layout CSV — A CSV with columns: well, key, concentration, dilution. Defines which wells are standards vs. samples.

Analysis runs automatically once both files are loaded.

Tabs & Charts

  • Standard Curve — Linear regression fit of standards (fluorescence vs. concentration). Shows slope, intercept, and R² value.
  • Experiment Summary — Mean ± SD chart with individual data points and summary statistics table showing n, Mean, SD, CV%, and relative yield per sample group.
  • Violin Plot — Kernel density estimation (KDE) showing the distribution shape of final concentrations per sample group, with individual data points, Q1–Q3 box, median, and mean markers.
  • Summary Table — Per-sample statistics: n, min, Q1, median, Q3, max, arithmetic mean, geometric mean.

Export Options

  • All Results CSV — Every well with calculated and final concentrations.
  • Clean Results CSV — Results with outliers removed.
  • Summary Stats CSV — Group-level statistics table.
  • PNG charts — Click the download button on any chart to save as PNG.

Push to Database

Validates your output columns match the existing P902_Results table schema, then commits the CSV directly to your GitLab repo. You need:

  • Git Project ID — Found in your GitLab project settings.
  • Branch — Usually main.
  • Personal Access Token — A GitLab token with api scope. Stored in your browser only.

File Clear Buttons

Click the × button on a loaded file card to remove it and start over.
