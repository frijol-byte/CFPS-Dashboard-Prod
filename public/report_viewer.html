Report Viewer — Help

View stored HTML reports

What this does

Displays any HTML report stored via the Report Upload tool. When GitLab is configured, the viewer loads reports from data/reports/ in the repo — visible to anyone with access. It also falls back to locally cached reports in IndexedDB.

How to use

  • Use the dropdown to select a report.
  • The report loads immediately in the viewer below.
  • Use New tab to open the report full-screen in a separate tab.
  • Use Download to save the original HTML file.

Data sources

Reports tagged REPO are stored in the GitLab repo and visible to all users. Reports tagged LOCAL exist only in your browser.

Deep linking

You can link directly to a report with report_viewer.html?id=REPORT_ID. The viewer in the Upload tool uses this.

Sandbox

Reports render with allow-scripts allow-same-origin, so Chart.js, Plotly, and other libraries work. Navigation within the iframe is confined.
