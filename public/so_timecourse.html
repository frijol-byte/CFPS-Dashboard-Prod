Kinetic fluorescence curves for salt optimization

Overview

This view shows fluorescence over time for each well in a salt optimization experiment, displayed as a grid of mini charts matching the plate layout.

Controls

  • Experiment & Lysate Lot — Select which experiment and lysate lot to view.
  • Y-Axis — Shared uses the same Y range across all wells for easy comparison. Individual auto-scales each well to show detail.
  • Inflection points — Marks the point of maximum growth rate on each curve (triangle marker).
  • Asymptotes — Shows the estimated plateau value as a dashed horizontal line.

Well Selector (Plate Map)

Click individual wells or click-and-drag to select a region. Wells with data are colored by their Mg/K condition. Only selected wells appear in the chart.

Chart

Each mini chart shows RFU vs. time for one well. Charts are arranged in a grid matching the plate layout. Hover a curve for exact values at each timepoint.

Summary Panel

Displays aggregate statistics for selected wells: mean endpoint fluorescence, top-performing well, and condition breakdown.
