SO Heatmap — Help

Mg/K condition heatmap for salt optimization

Overview

This view displays a 2D heatmap of fluorescence values for each Mg/K concentration combination tested in a salt optimization experiment.

Controls

  • Experiment & Lysate Lot — Select which experiment to view. The dropdown lists experiments from your local cache and the database.
  • Metric — Choose Mean, Geometric Mean, Max, or Min fluorescence for the heatmap color scale.
  • Show values — Toggle numeric labels inside heatmap cells.
  • Log scale — Apply logarithmic color scaling for wide dynamic ranges.

Heatmap

Rows represent Mg concentrations, columns represent K concentrations. Color intensity maps to fluorescence. The top 3 performing conditions are starred. Hover any cell for exact values.

Top 3 Table

Shows the three best Mg/K combinations ranked by the selected metric, with mean, SD, CV%, and replicate count.

Export

  • SVG / PNG — Download the heatmap as a vector or raster image.
  • All Data CSV — Export the full aggregated dataset.
  • Top 3 CSV — Export only the top 3 conditions.

Push to Database

Commits the merged time-course data as a CSV to data/P902_SO_Results/ in your GitLab repo. The pipeline rebuilds the database automatically.
