Page Overview

This is the landing page for the JCM-Claude Analyzer Toolkit — a suite of browser-based tools for cell-free protein synthesis (CFPS) analysis and product tracking.

Processing Tools

  • AbsQuant Data Processing — Upload plate reader Excel files and plate layouts. Runs standard curve regression, quantifies samples, removes outliers, and exports CSVs and charts. Start here to process raw data.
  • Salt Optimization — Upload multi-timepoint plate reader Excel files and plate layout CSVs to identify optimal Mg/K concentrations. Generates 2D heatmaps showing mean fluorescence per condition and time-course analysis with Vmax and inflection point detection.

Data Analysis

  • Data Review Dashboard — Load processed CSV results into an interactive dashboard. Explore experiments, compare conditions, view plate heatmaps, reproducibility, and standard curves across multiple experiments.
  • Graph Builder — Drag and drop columns from any lot or experiment CSV to create custom scatter plots, bar charts, pie charts, and heatmaps. Supports multiple variables per axis, color grouping, aggregation modes, and local data filters. Read-only access to all data.
  • P902 Data Browser — Query the experiment database directly in your browser with SQL. The database is automatically built from CSVs committed to the repo — no server needed.
  • Report Generator — Generate publication-ready experiment reports with one click. Choose a template (Quick QC, Full Analysis, or Executive Summary), filter data by product, dilution, operator, etc., group statistics by any dimension with optional sub-grouping, and add custom annotations with rich text formatting. Export as PDF or standalone HTML. Supports batch mode for multi-experiment reports.

Product Tracking

  • CFPS Lot Browser — Browse, search, and manage all P902 lot records including fermentation, lysate, master mix, standard curves, controls, plasmids, and more. Add new entries and push to GitLab.
  • CFPS Lot Raw Editor — Directly edit the raw CSV lot data tables with inline cell editing. Add/delete rows, rename columns, and push changes back to GitLab.
  • Gantt Chart Studio — Plan and visualize project timelines with a full-featured Gantt chart. Import/export CSV, set task dependencies, filter by column, color-code by product or assignee, and export as SVG or PNG.

Reports

  • PD Report Upload — Upload self-contained HTML report files (from Claude, Jupyter, R Markdown, etc.) and store them in data/reports/ via GitLab sync. Reports are shared with anyone who has repo access, and also cached locally in IndexedDB.
  • PD Report Viewer — Select any stored HTML report from the GitLab repo or local cache and render it live in a sandboxed iframe. Open in a new tab, download the original file, or deep-link to a specific report. Reports from the repo are visible to all users.

Typical Workflow

1. Process raw plate reader data with AbsQuant → 2. Push processed CSV to the repository → 3. Explore results in the Dashboard → 4. Generate experiment reports with the Report Generator → 5. Track reagent lots in the Lot Browser → 6. Build custom charts across all data with the Graph Builder.
