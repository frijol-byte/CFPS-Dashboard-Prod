Report Generator

Create publication-ready experiment reports with one click.

Quick Start

  • Choose a template that fits your needs
  • Select one or more experiments (multi-select for batch reports)
  • Toggle individual sections on/off to customize
  • Click Generate Report to preview

Templates

  • Quick QC — Single-page pass/fail check with KPIs and standard curve R²
  • Full Analysis — Everything: charts, heatmap, spike-in, statistics, and optional well data
  • Executive Summary — High-level KPIs and commentary

Filters

Use the Filter Data panel to exclude unwanted data before the report generates. For example, filter to only 400x dilution, or exclude neg/control products. Filters apply to all selected experiments. The sample count updates in real time.

Grouping

The Group Statistics By selector controls how box plots and statistics are broken down. Choose a primary group (e.g., Product) and optionally a sub-group (e.g., Operator) to create cross-tabulated labels like "Premium / JC". This matches the Group + Sub selector in the main dashboard.

Custom Comments

Each report section has an Add comment button. Click it to type a note that appears alongside the data. Comments are included in HTML exports and printed reports — perfect for adding context, observations, or action items next to specific charts.

Batch Reports

Select multiple experiments to generate a combined report with page breaks between each. Each experiment gets its own full analysis section.

Sections

  • Key Metrics — Mean, median, CV%, well count, outliers, R²
  • Auto-Commentary — Automated findings: R² value, outlier counts, CV%, edge effects
  • Standard Curve — Scatter plot with fit line, equation, and R²
  • Distribution — Histogram of cleaned concentration values
  • Group Box Plot — Box plots grouped by product, lysate, operator, etc.
  • Plate Heatmap — 384-well Viridis heatmap of RFU values
  • Spike-in Analysis — Spike-in CV% by dilution factor
  • Group Statistics — Detailed table with mean, median, SD, CV%, min, max, outliers per group
  • Well-Level Data — Raw data table (first 200 rows), outliers highlighted in red

Exporting

  • Print / PDF — Browser print dialog (choose "Save as PDF" for PDF)
  • Export HTML — Standalone HTML file with embedded fonts

Data Source

The badge in the header shows whether you're viewing Live Data (from cfps.db via IndexedDB) or Demo Data (generated sample data for preview). When deployed alongside the dashboard, live data loads automatically.
