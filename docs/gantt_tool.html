Gantt Chart Studio — Help

Project planning with timeline visualization

Getting Started

  • Import CSV — Upload a CSV file to populate tasks. Columns are auto-detected by header name.
  • Template CSV — Download a blank CSV with all column headers to fill in externally and re-import.
  • Add Task — Add a new empty task row. You can also type directly into the ghost row at the bottom of the table.
  • Clear All — Remove all tasks, filters, and saved data. This cannot be undone.

Column Reference

  • # — Row number / task ID. Used by Predecessor to create dependency links.
  • Activity — Name of the task, displayed on the chart bar.
  • Description — Additional details, visible in the table and tooltip on hover.
  • Start / End Date — Accepts M/DD, M/DD/YYYY, or YYYY-MM-DD. If end date is blank, defaults to start + 4 days.
  • Product — Built-in options: CFPS, T7, Pichia, MutS, sfGFP, Other. Custom values from CSV are also accepted.
  • Assignee — Primary assignee. Used for Color By grouping.
  • Pred (Predecessor) — Enter the task # that must finish before this task starts. Dependency arrows appear automatically on the chart.
  • Status — Not Started, In Progress, or Complete. Set directly via dropdown.

Editing Tasks

  • Inline Editing — Click any cell in the table to edit it directly. Changes are saved automatically.
  • Delete Task — Click the trash icon on the right side of any row to remove it.
  • Dependencies — Set a task's Predecessor column to another task's # number. An arrow will appear on the chart.

Filtering & Coloring

  • Column Filters — Right-click any column header to open a filter menu. Check/uncheck values to show or hide matching rows.
  • Color By — Use the dropdown in the legend bar to group tasks by Product, Assignee, Status, or Activity Type.

Keyboard Shortcuts

  • Click a cell to select it. Shift+Click to select a range.
  • Ctrl+C / Ctrl+V — Copy/paste cells (tab-separated, works with Excel/Sheets).
  • Ctrl+D — Fill down: copy first selected row's values into rows below.
  • Esc — Clear selection and close menus.

Exporting

  • SVG — Scalable vector graphic, ideal for presentations.
  • PNG — High-resolution (2x) raster image of the chart.
  • CSV — Export currently visible (filtered) tasks.

All changes are saved to your browser automatically via Local Storage.
