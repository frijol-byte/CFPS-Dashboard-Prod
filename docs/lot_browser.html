Lot Browser — Help

Browse, manage, and track P902 reagent lots

Navigation

Use the tabs across the top to switch between lot categories: Fermentation, Lysate, Master Mix, Standard Curves, Controls, CF Product, Plasmid, Premix, Pre-SO MM, Solubility Enhancer, Delivered Material.

Table Features

  • Search — Type in the search bar to filter rows in real-time across all visible columns.
  • Sort — Click any column header to sort ascending/descending.
  • Computed Columns — Some columns are auto-calculated from formulas (shown with a formula chip). These update automatically.

Charts & Stats

Below the table, distribution histograms and summary statistics are shown for numeric columns. Text columns show unique value counts.

Add New Entry

Click + Add Entry to open a modal form. Fill in the fields and click Save. The new row appears in the table immediately.

Export & Push

  • Export CSV — Download the current lot table as a CSV file.
  • Push to GitLab — Commit the updated CSV directly to your repository. Configure your GitLab Project ID, Branch, and Personal Access Token in the settings section.
