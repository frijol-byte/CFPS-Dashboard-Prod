Graph Builder — Help

JMP 19-inspired interactive data visualization tool

Getting Started

1. Click a data source in the left sidebar to load a table. 2. Drag column chips from the Columns list into the drop zones (X, Y, Color, Size, Wrap) arranged around the chart. 3. The chart renders instantly and updates live as you change settings.

Adding Columns to Zones

  • Drag & drop — drag a column chip onto any labeled drop zone around the chart
  • Double-click — double-click a column chip to auto-assign it (numeric → Y first, categorical → X first, then Color, then Wrap)
  • Drag onto chart — drop a column directly on the chart area: bottom edge → X, left edge → Y, right edge → Color, center → auto-assign by type
  • Click the × on any assigned chip to remove it from its zone
  • Multiple columns — X and Y accept multiple columns for multi-axis scatter (side-by-side panels with shared Y scale)

Drop Zones

  • X (bottom) — primary horizontal axis. Accepts numeric or categorical columns
  • Y (left) — primary vertical axis. Accepts numeric columns
  • Color / Group (right) — splits data by a categorical variable with distinct colors. Colors are consistent across faceted panels
  • Size (right) — scales point radius by a numeric variable (scatter only)
  • Wrap / Facet (top) — creates one chart panel per unique value of the selected column (trellis/facet layout)

Chart Types (10)

  • Points — scatter plot. Supports color grouping, size scaling, jitter, multi-axis panels, smoother, regression line, confidence band, error bars, rug marks, and mean/median reference lines
  • Bar — grouped bar chart. Default aggregation is sum; switch to Mean, Median, etc. via the Statistic dropdown. Supports error bars and color grouping
  • Box — box-and-whisker plot showing Q1, median, Q3, 1.5×IQR whiskers, and outliers. Optional jittered data points overlay. Supports color sub-grouping
  • Histogram — auto-binned frequency distribution of a numeric X variable. Supports grouped overlay by Color column with transparency
  • Violin — kernel density estimation (KDE) mirrored around each category. Shows median line and IQR box inside the density shape. Optional jittered points
  • Line — connected line chart, aggregated per X value. Supports color grouping and error bars
  • Area — stacked area chart. Uses the Color column for stacking groups
  • Heatmap — two categorical axes with aggregated values shown as color intensity (Viridis scale). Drop a numeric column in Color zone to set the value
  • Pie — donut chart. X = label categories, Y = values (aggregated)
  • Treemap — nested proportional rectangles. X = categories, Y = values

Properties Panel (left sidebar)

  • Statistic — aggregation mode: None, Mean, Median, Sum, Count, Min, Max. Affects how multiple Y values per X group are combined. For scatter, switching to Mean/Median shows large diamond markers at aggregated positions with faded raw points behind, connected by dashed lines
  • Error — toggle error bars and select type: SD, SEM, 95% CI, 99% CI, Range, or IQR
  • Jitter — add random horizontal displacement to reduce overplotting on categorical axes. Adjustable amount slider (0–100%)
  • Sort — category ordering: Default, A→Z, Z→A, ↓ Value (descending sum), ↑ Value (ascending sum)
  • Opacity — point/bar fill transparency (5–100%)
  • Pt Size — base point radius (1–20px)

Overlays (left sidebar)

  • Smoother (LOESS) — locally weighted regression curve overlay (scatter with numeric X only)
  • Line of Fit — OLS linear regression line with R² displayed in the chart corner
  • Confidence Band — 95% confidence interval shaded region around the regression line
  • Connect Means — dashed line connecting aggregated summary markers (on by default when aggregating)
  • Rug Marks — small tick marks on X and Y axes showing individual data point positions
  • Mean Line — horizontal reference line at the overall Y mean (red dashed)
  • Median Line — horizontal reference line at the overall Y median (purple dashed)

Axes

Log X / Log Y — toggle logarithmic scale for either axis. Values ≤ 0 are automatically excluded when log scale is active.

Filters

Click the ▼ Filters bar to expand. Each column appears as a button — click it to open a dropdown. Categorical columns show searchable checkboxes with All/None/Invert shortcuts. Numeric columns show Min/Max range inputs. Active filters are highlighted with a count badge. Columns are sorted alphabetically.

Annotations

  • T Text — click the button, then click on the chart to place a text label. Type your text and press Enter
  • → Arrow — click the button, click a start point, then click an end point to draw an arrow
  • ✕ Clear — remove all annotations
  • Double-click any annotation to delete it individually
  • Annotations work on both the main chart and individual facet/wrap panels
  • Annotations persist across chart updates until cleared

Right-Click Editing

Right-click any text element on the chart (axis labels, tick labels, facet panel titles, annotation text) to edit it in place. Changes are display-only and don't alter the underlying data. Edits persist until the chart re-renders.

Tooltip Customization

Click ⚙ Tooltip in the toolbar to open the column picker. In Auto mode (default), tooltips show X, Y, and Color values. Uncheck Auto to manually select which columns appear in hover tooltips — useful for showing metadata like operator, lot ID, or plate position.

Zoom

Use the − / + buttons in the toolbar to shrink or enlarge the chart (40%–200%). The percentage readout shows the current scale. Reset returns to 100%.

Export

  • ↓ SVG — download the chart as a vector SVG file (lossless, editable in Illustrator/Inkscape)
  • ↓ PNG — download as a 2× resolution raster image (suitable for presentations and documents)

Local CSV Upload

  • Local CSV Upload — Drag-and-drop any CSV file onto the "Local Files" area in the sidebar, or click to browse. The file is parsed in your browser and appears as a data source alongside database tables. Click × to remove.

Keyboard Shortcuts

Escape — close this help panel, cancel an in-progress annotation, or close the tooltip config
