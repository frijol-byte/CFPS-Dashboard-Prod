Standard Curve QC

Each experiment gets its own mini-chart showing standards (blue circles), the linear regression fit line (dashed blue), sample points (× markers), and spike-in points (yellow circles). Background color indicates R² quality:

  • Green — R² ≥ 0.99 (good)
  • Amber — R² ≥ 0.98 (acceptable)
  • Red — R² < 0.98 (poor — investigate)

Spike-in Analysis

If your data includes spike-in wells (key contains "spike-in"), this section shows back-calculated concentrations grouped by dilution factor, with mean RFU, SD, CV%, and mean mg/L.

Lot Tracking

Tracks Lysate/Master Mix lot combinations across experiments. Shows mean concentration ± SD as connected dots. Useful for monitoring lot-to-lot consistency over time.
