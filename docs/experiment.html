Experiment Deep Dive — Help

Detailed analysis of a single experiment

Experiment Selector

Use the dropdown at the top to choose which experiment to analyze. All charts and tables update to show data from that experiment only.

Panels

  • Concentration by Group — Bar chart of mean concentrations, grouped by a selectable metadata field (Product, Lysate, etc.).
  • Summary Stats — Table of per-group statistics for the selected experiment.
  • Plate Heatmap — Full 384-well heatmap. Standard wells are dimmed to highlight sample distribution.
  • Standard Curve — Experiment-specific standard curve with R² quality indicator and data points.
  • Well Data Table — Paginated list of all wells. Use ← → buttons to navigate pages. Click ⬇ Export to download as CSV.
  • Spatial Analysis — Edge Effects — Compares concentrations in edge wells vs. interior wells to detect plate edge effects.

Filters

Global filters at the top still apply — the experiment view shows filtered data within the selected experiment.
