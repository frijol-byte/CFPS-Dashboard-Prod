Overview Dashboard — Help

Multi-experiment overview with interactive charts and filters

Filters Panel

Click ▾ Filters to expand/collapse. Toggle individual filter chips to include or exclude specific values. Click ALL to select or deselect all options for a filter category. Available filters: Exp ID, Template, Rxn Vol, Lysate, Master Mix, Product, Operator, Test Condition.

KPI Cards

Six summary metrics across the top: Filtered sample count, Mean concentration (mg/L), Median, CV%, Experiment count, and Outlier count.

Charts

  • Control Chart — Mean ± SD per experiment. Use the Group and +Sub dropdowns to change grouping (e.g., by Product, Lysate, Operator). Connected lines show trends.
  • Distribution (Boxplot) — Box-and-whisker plots with jittered data points. Red open circles indicate IQR outliers. Configurable grouping.
  • Plate Heatmap — Select an experiment from the dropdown. Wells are colored by fluorescence intensity (Viridis scale). Standards are highlighted with a purple border.
  • Pie Chart — Slice by any metadata field. Toggle between Count and Mean sizing.
  • Summary Table — Mean, Median, SD, CV% per group. CV% is color-coded: green (<15%), amber (15–30%), red (>30%).
  • Relative Yield — Horizontal bars comparing group means.
  • Per-Experiment — Box plots for every experiment side-by-side.

Zoom & Pan

All SVG charts support: Scroll to zoom, drag to pan, double-click to reset.

Navigation

Use the tab bar at the top: Load Data → Overview → Curves & Lots → Experiment → Raw Data → Reproducibility.
