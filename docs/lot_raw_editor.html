Lot Raw Table Editor — Help

Directly edit lot CSV data with inline editing

Navigation

Use tabs to switch between lot CSV files. Each tab corresponds to a file in data/lots/.

Editing

  • Click a cell to edit its value inline. Press Enter or Tab to confirm. Press Esc to cancel.
  • Changed cells are highlighted so you can track your edits.

Row Operations

  • Add Row — Appends a new empty row to the bottom of the table.
  • Select Rows — Click the row number to select/deselect a row.
  • Delete Selected — Removes all selected rows (with confirmation).

Column Management

Click Edit Columns to open the column editor. You can add new columns, rename existing ones, reorder them, or delete columns.

Search & Sort

Use the search bar to filter rows. Click column headers to sort.

GitLab Integration

  • Pull from GitLab — Fetch the latest CSV data from the repository, replacing your local copy.
  • Push to GitLab — Commit all your changes back to the repository. A change summary is shown before pushing.

Change Tracking

The footer bar shows the number of edits, new rows, and deleted rows. This helps you review changes before pushing.

Export

Click Export CSV to download the current table state as a CSV file.
