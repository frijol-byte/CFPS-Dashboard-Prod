Report Upload — Help

Store HTML reports for viewing in the Report Viewer

What this does

Upload self-contained HTML report files (like those generated by Claude, Jupyter, R Markdown, etc.) and store them in the GitLab repo under data/reports/. When GitLab is configured, reports are committed to the repo so anyone with access can see them. Reports are also cached locally in IndexedDB.

How to use

  • Configure GitLab sync (same credentials as Lot Browser / Raw Editor) so reports are shared.
  • Drag & drop .html files onto the upload zone, or click "browse files" to select them.
  • Give each report a display name (auto-filled from filename).
  • Click Store reports to save them to GitLab and to the local browser cache.
  • Use Pull in the GitLab panel to refresh the list from the repo.

Viewing reports

Once stored, use the Report Viewer tool to select and view any report in a sandboxed iframe. Reports from GitLab are visible to all users.

Storage

GitLab (shared): HTML files are committed to data/reports/ with an _index.json manifest. Anyone with repo access can see them.

IndexedDB (local fallback): Reports are also cached in the browser. If GitLab is not configured, reports are stored locally only.
